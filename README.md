# Sales-Controlling-Report---AdventureWorks
Raport Controllingowy w Power BI (AdventureWorks)  Analiza rentowności i identyfikacja produktów generujących straty.  🔹 Kwestie techniczne: zapytania SQL + modelowanie relacyjne (Star Schema). 🔹 Strony raportu: • Overall Condition (trend zysku) • Cause of Losses (analiza strat) • Geographic Analysis (geografia sprzedaży)
